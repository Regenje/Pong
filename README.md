# Pong

Un Pong classique dans le navigateur, joueur contre ordinateur. Un seul fichier HTML, aucune dépendance.

## Jouer
- **W/S** ou **↑/↓**, ou la souris / le doigt pour bouger la raquette
- **Espace** : pause
- **1 / 2 / 3** : difficulté (facile / normal / difficile)
- Premier à 7 points

En local : ouvre simplement `index.html` dans un navigateur.
